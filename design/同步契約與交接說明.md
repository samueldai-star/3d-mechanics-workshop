## 2. 唯一的兩個接點

### 接點 A — 角落定義 `CORNERS`

位於 `力學3D工坊.dc.html` 的 logic class 最上方。每個角落一筆：

```js
{
  id: 'vector',              // 穩定 key，repo 端以此對應模擬器模組
  title: '力的合成分解',
  sym: 'F₁ + F₂ = ΣF',
  pos: [-5.0, 2.6, -3.2],    // 3D 世界座標，hotspot 標記掛點
  formula: 'ΣF = F₁ + F₂',
  readouts: [{ k: 'F₁', v: '—— N' }, …]   // 面板右欄的即時數據列
}
```

目前四筆：`vector`（力的合成分解）、`spring`（彈簧張力）、`normal`（正向力）、`friction`（摩擦力，佔位、不可點）。

新增角落 = 在 repo 加一筆 + 一個模擬器模組，場景端不需改動。

### 接點 B — 面板中央模擬區

面板結構固定為：標題列 / 中央模擬區 / 下方公式列 / 右側數據欄。
中央那塊虛線框（`SIMULATION CANVAS`）是模擬器的掛載槽。

建議的模擬器介面：

```ts
interface Simulator {
  id: string;                       // 對應 CORNERS.id
  mount(el: HTMLElement): void;     // 掛進中央模擬區
  unmount(): void;
  onReadouts(cb: (r: {k: string; v: string}[]) => void): void;  // 回報右欄數值
  reset(): void;                    // 對應面板「回到工坊全景」時的清空
}
```

場景端只負責：開啟角落 → 建立 slot → `mount(slot)`；關閉 → `unmount()`。
模擬器不得自行改動面板底色、標題列、公式列。

## 3. 視覺規範（設計端負責，repo 端請勿改）

- **場景瀏覽狀態**：暗調、暖光、高對比。背景 `#120b06`，鍛爐橘光 `#ff7a24`、燈籠 `#ffab4d`。
- **模擬器面板狀態**：**必須維持亮底**（`#f2e2c6 → #e5cda6` 暖木漸層），供老師在旁白板板書時投影不吃光。面板內對比收斂，文字主色 `#2f1d0c`。
- 字體：`Noto Serif TC`（標題／公式）、`Noto Sans TC`（介面）、`IBM Plex Mono`（符號與數值）。
- 公式列字級不小於 30px、數值不小於 24px（投影可讀性）。

## 4. 場景端已實作、repo 端可直接沿用

- three.js r161（ESM），OrbitControls。
- `buildWorld()`：程序化木紋材質、樑架、燈籠點光、鍛爐閃爍、齒輪旋轉、粉塵粒子，全部無外部資產。
- 鏡頭：軌道模式 / 漫步模式（WASD、方向鍵、Shift 加速）、`tween()` 平滑轉場、`focusCorner(i)` 帶鏡頭到角落。
- `projectHotspots()`：3D 座標投影成 HTML 標記位置，含距離淡出與縮放。
- 右下視角控制盤（觸控／投影環境用）、全螢幕投影、回到全景。
